# 板块打法

这份把两样东西合在一起：**基础公式**（团队课程定下的框架，必须照走）+ **高手打法**（上千条高转化朋友圈按板块拆出来的具体写法）。
先确定板块，读对应一节，选定一种打法再动笔。

## 所有板块通用的四条

1. **第一句是她的观点、状态或一个问句，不是事情经过。**不要写「今天有个姐妹找我说……」。
2. **截图放证据，文字写反应。**聊天内容截图里都有，正文不复述，事情一两句带过，篇幅留给她这个人的想法、情绪和态度。
3. **借这件事，说一个她自己的道理。**晒单不是报喜，是借这一单讲她怎么看人、看钱、看成交。
4. **能量要在。**读完的人，对她、对这件事，信心多了还是少了？

## 一、晒单圈

**基础公式**：开头直接介绍客户 → 她为啥选我、选这个产品 → 升华。讲她的故事，不是只晒个单；体现红红火火。
长度：中位约 220-260 字，七成以上是长文；一句话晒单只偶尔穿插。

| 打法 | 怎么写 | 示范 |
|---|---|---|
| ① 观点开头 | 第一句直接抛观点，这一单只当证据 | 「人和人的差别，就在下决定的那一下。」→ 她怎么下的决定 → 我怎么看 |
| ② 给这个人起标题 | 第一句是她的身份标题，再讲她这个人 | 「45 岁姐姐的第二回合，我的骄傲。」→ 认识多久、怎么走到今天 |
| ③ 从难缠写到认可 | 先写她多难搞，再写她变了 | 「这个姐姐，我足足聊了八天。」→ 她的犹豫、原话 → 现在什么样 |
| ④ 这一单勾出我的过去 | 由她想到从前的自己 | 「看到她，我想起第一次掏钱学东西的自己。」 |
| ⑤ 情义 | 她记着你什么，你记着她什么 | 「她说过一句……我记到现在。」 |
| ⑥ 短句穿插 | 一两句状态 + 截图，只偶尔用，用来表现红火 | 「睡一觉醒来，又多一个。」 |

**复购、升级的单子**：重点写「她自己回来了」和你的底气，用打法①或②。功效原话不写（见 `产品与合规.md`）。

**别这样写**：照着聊天记录复述；只晒金额；通篇在说产品。

## 二、招商圈

**基础公式**：不管讲学员、老师、同伴、品牌、团队多牛，**一定转回自己身上**：我的变化、我的故事、我在这里的成长。

| 打法 | 怎么写 |
|---|---|
| ① 一个人的前后 | 她来之前什么样，现在什么样，最后落到「带她的过程中我变了什么」 |
| ② 一群人的前后 | 第一次见面时什么样，几个月后什么样，用一个寒碜的小细节开头 |
| ③ 团队里的一幕 | 早上打开群看到什么、谁在做什么，我被什么感动 |
| ④ 问题开头 | 「你迷茫的时候会怎么做？」→ 我的做法 → 我身边的人 |
| ⑤ 底气宣言 | 敢说自己想要什么、能带人走到哪，紧接一句自黑 |
| ⑥ 收徒当天 | 她今天才进门，还没有变化可写：用她的一句话开头，转回过去同样迈这一步的我，把丑话说在前面 |

收减脂教练的圈归晒单还是招商不用纠结：公式都走，「介绍这个人、为啥选」+「转回自己」。

**别这样写**：晒收入、承诺月入多少、鼓励借钱或刷信用卡入局、拿「穷」刺激人。

## 三、学员反馈圈

**基础公式**：肥胖类型 → 瘦身过程 → 瘦身结果。

| 打法 | 怎么写 |
|---|---|
| ① 结果加问号 | 第一句把真实结果写成问句：「42 天瘦 11.6 斤？」 |
| ② 小变化开头 | 第一句写生活里的小不同：「她终于敢站到合影中间了。」 |
| ③ 她的认真 | 重点写她做对了什么，再落到「一个人对一件事的认真，就是她对所有事的标准」 |
| ④ 我的共鸣 | 写到一半落回我自己也走过的路 |

结果必须是这个人的真实数据，说明她同时做了什么，不写成承诺。

## 四、产品圈

**基础公式**：产品铺垫、产品打卡、硬广软广、晒对比图四类。销售的目的是传递对产品的信心。

| 打法 | 怎么写 |
|---|---|
| ① 生活场景 | 产品出现在她的日子里：一边喝一边回消息，出差箱子里塞了几袋 |
| ② 舍不得 | 自己都不够喝、藏起来、被人拿走的小糗事 |
| ③ 家人用 | 老公怎么吐槽、怎么偷喝（孩子不写） |
| ④ 观点带产品 | 先讲一个道理，产品最后一句轻轻带过 |
| ⑤ 答疑 | 把真实被问的问题当第一句 |

普通食品不写功效，理念讲怎么吃饭，不讲产品的作用。

---

## 五、全方位分享

**基础公式**：日常分享（家庭、兴趣、好物）+ 核心分享（撕裂自己、展示野心）。每天一条长文，像连续剧。
长文的总逻辑：**观点 → 自己的故事 → 自己的改变**，首尾呼应。

打法按 `心动写法.md`。家人、我和金钱、我和他人是最高频的系列。

---

## 六、价值输出

**基础公式**：不摘鸡汤，借一句话讲自己的感悟和改变。早起、读书笔记、每日复盘用连续数字制造震撼。
观点圈按 `说服写法.md`。读书笔记不打广告。

---

## 七、长短搭配

一天里长短要错开：长文讲透，短句穿插。短句圈要靠这几招才有人看：
- 一句状态 + 自黑：「收完这单，手机先没电了，我比它先没电。」
- 一句狂 + 一句怂
- 一句截图反应
