# 朋友圈写法拆解

这份是写法的总纲：从上千条高转化朋友圈里拆出来的文风、开头、结尾和圈型结构，已经换成减脂教练的场景。每次写之前必读。

---

## 一、数据画像（发多少、什么时候发）

- 高手的节奏：**日均 6-10 条**，忙的时候更多。
- 长短搭配：四分之一是一两行的"一句话圈"，一半在 90 字以内，四分之一是 200 字以上的长故事。
- 时段：早上 6-8 点起量，**8-10 点最高峰**，白天均匀分布，**晚上 21-23 点发当天最走心的长文**。
- 故事是核心竞争力。只转语录、只发广告的朋友圈，越发越没人看。通读下来，语录和广告最密集的那几段，恰恰是最平的；让人心动的全是"一个具体的人 + 一件具体的旧事"（见 `心动写法.md`）。
- 朋友圈是长期复利：很多人第一次买单，是因为已经默默看了你一两年。

---

## 二、文风（写得"像真人"的关键）

1. **说人话**。像给闺蜜发语音：不修辞、不排比、不端着、不用成语堆砌。
2. **短句**。一句 5-15 个字，一个意思一个句号。长圈靠句子短撑住节奏。
3. **情绪口头词**：天呐 / 好气 / 哈哈哈 / 扎心了 / 开心到冒泡 / 我的老天。每条 1-2 个，多了就假。
4. **固定口头禅**：每个人可以有自己的 1-2 个标志性说法（写在个人档案里），反复用，读者一看就知道是你。
5. **炫完马上自黑**。晒成绩之后跟一句自嘲：
   - 「这个月带瘦了 30 个人……我自己却胖了 2 斤，因为天天陪她们吃。」
   - 「凌晨还在回学员消息，手机快没电了，我比手机先没电。」
6. **数字写具体**：118.6 斤→112.2 斤；腰围 82→76cm；早起第 87 天；21 天营瘦了 7.2 斤。数字就是可信度。
7. **整条只留一句能被截图的狠话**：「你对自己的标准，就是你的体重。」「瘦是一种生活方式，不是一段时间。」只要一句，别每段都金句。
8. **借别人的嘴夸自己**：老公的话、学员的私信、闺蜜的留言、孩子的作文。自己只配一两句。
9. **图是证据**：学员体重截图、餐盘照、对比照、手写复盘、聊天记录（打码）。文字说结论，图来证明。

## 三、开头的 12 种钩子（第一句决定点不点"全文"）

第一句就是标题，后面直接接正文。

| 钩子 | 示范 | 适合 |
|---|---|---|
| ① 数据问句 | 「21 天瘦 7 斤？」「5 天，腰围少了 3 厘米？」 | 学员反馈圈：结果加问号放第一句 |
| ② 挑衅反问 | 「不吃晚饭就能瘦？」「减肥一定要饿肚子？」 | 观点圈、误区圈，引评论 |
| ③ 自问自答 | 「为什么我五点起床？哦，因为孩子六点半醒。」 | 动机圈、家庭圈 |
| ④ 反常识断言 | 「减肥最快的方法，是好好吃饭。」「越饿越瘦不下来。」 | 价值圈 |
| ⑤ 场景还原 | 「晚上十一点，站在冰箱前，手已经伸向了那块蛋糕……」 | 生活糗事、情绪圈 |
| ⑥ 标题句 | 「妈妈瘦了，全家都会变好」 | 标题 + 讲故事 |
| ⑦ 别人的问题 | 「有人问我：生完孩子三年了，还能瘦吗？」 | 答疑圈 |
| ⑧ 前后对比 | 「三个月，这群妈妈到底经历了什么？」 | 逆袭圈、招商圈 |
| ⑨ 自曝 | 「说个丢人的事。」「我身上有个特别大的毛病。」 | 撕裂自己、示弱 |
| ⑩ 惊叹 | 「天呐，她居然穿上了 M 码！」 | 好消息、晒单 |
| ⑪ 时间锚点 | 「2025.3.1，这是值得记住的一天。」「这是我住了 18 年的老房子。」 | 里程碑、回忆 |
| ⑫ 立 flag | 「立个 flag：今年带 200 个姐妹健康瘦下来。」 | 野心圈 |

## 四、结尾的 5 种收法（同一天要轮换）

1. **一句金句收**：「你看到的轻松，都是她熬过来的。」
2. **自嘲小尾巴**：「好了，我去吃我的水煮菜了。」「请叫我戏精教练。」
3. **轻召唤**：「想瘦的姐妹，来找我。」「需要食谱的扣 1。」
4. **感谢某人**：「谢谢你，有你在真好。」
5. **戛然而止**：故事讲完就停，不总结（生活圈、糗事圈常用）。

长故事一半不带广告；带广告的那一半，也只用一两句。

## 五、圈型结构（17 种）

### A. 一句话圈（占四分之一，填时段、立价值观）
- 早上：「五点半的厨房，只有我和一锅小米粥。」
- 白天：「一懒就胖。」「好好吃饭，是最难的自律。」
- 公式型：「吃对 + 睡好 + 动起来 = 瘦」
- 规则：两行以内，不带广告，配风景/餐盘/自拍。

### B. 早起 / 打卡（固定格式，每天一条）
```
早起第 N 天（或：减脂打卡第 N 天）
［今天的一个小画面，1-2 句］
［一句小目标或固定口号］
```
数字连续 + 每天一个新细节，是最稳的"自律"证明。

### C. 读书笔记（系列编号 #XX#DayN）
```
#系列名#DayN
［一句主题句（从「观点库/读书笔记」选）］
［"这句话我太有体会了"→ 自己的一段经历或数据］
［一句收尾 / 生活小尾巴］
```
读书笔记里**不打广告**。

### D. 每日复盘（#每日复盘#DayN）
```
#每日复盘#DayN
［一句自我反思，承认一个小毛病］
明天安排：1.… 2.… 3.… 4.早点睡，这也是工作的一部分
晚安@城市
```

### E. 全方位分享 · 家人（最高频的长故事）
**一个具体场景 / 一句对话 → 往回挖一段过往 → 落到"我变了 / 我懂了" → 谢谢 TA**
- 一定有一句原话对白、一个具体物件（一碗面、一件旧外套、一张老照片）。
- 老公、父母的形象要真实：有缺点、有转变，像连续剧一样一条条写下去。

### F. 核心分享 · 撕裂自己
**一件当下的小事 → 挖到最痛的过往（胖、穷、自卑、被看不起）→ 释放 → 新的决定**
- 例：「今天给自己买了一条裙子，没看价格。」→ 下一条讲：从小到大衣服都是表姐穿剩的、胖的时候只敢穿黑色……

### G. 展示野心 / 金钱观
- 年度目标清单：「今年目标：1.… 5.…」+「好了，又开始吹牛了。」
- 怂着立 flag：「发这条的时候手都在抖，怕被人笑。」
- 金钱观用家人小事演出来：带妈妈买衣服她只看打折区；爸爸说"这顿凑合一下"。

### H. 别人眼中的我
截图别人的话（老公、学员、同学、孩子），只配一两句：「哈哈，这次让你露个脸。」「看完有点想哭。」

### I. 学员反馈（零售核心）
```
［数据问句：XX 天瘦 X 斤？］
［这个人是谁：身高、体重、身份、之前的困扰］
［过程里一个真实细节：没饿肚子、吃了火锅、哺乳期、老公也跟着瘦了］
［我的情绪：每天早上看大家数据好开心］
［一句原理（从「观点库/减脂营养」选）］
［轻召唤，或不召唤］
```
最好的反馈 = **数字 + 内在变化**：「30 天瘦了 8.8 斤，腰围小了 9 厘米。她说：以前发朋友圈都不敢发自拍，现在想天天发。」

### J. 自己当小白鼠
「减脂打卡第 7 天：4 号 114.6 斤，今天 10 号 112.2 斤。这周还吃了一顿火锅。」日期 + 体重 + 反差的生活细节 + 惊叹。

### K. 产品 / 服务介绍
- **先抑后扬**：「第一眼觉得包装好土，送给同事了 → 她一个月后告诉我睡得好多了 → 我才认真去了解 → 第一、第二、第三。」
- **"为什么找我"三段论**：1. 方法/产品 2. 我这个人 3. 我的团队。
- **答疑式**：「有人问我……」→ 坦诚回答。
- **藏在家庭小事里**：老公炒了一盘木耳 → 顺便讲木耳为什么适合减脂期。
- **价格自嘲**：「我是个记不住价格的教练，又被学员纠正了：是 XXX 元，XXX 元。」
- 产品功效一律用**顾客原话**，不自己下结论（见 `产品与合规.md`）。

### L. 晒单 / 收学员
**介绍这个人 → 她为什么选我（看了我多久、哪条圈打动她）→ 我的感受 → 一句升华**
晒单讲的是人和情义，不是截图和金额。

### M. 招商（招减脂教练）
- 讲一个教练的变化：「她做教练前是全职妈妈，三个月后带瘦了 12 个人，她做对了什么？」
- 夸人先抑后扬再补刀：「我很少夸人。她的方案改了五遍都不过……现在比我写得还好。就是字还是丑。」
- 同一群人的前后对比：第一次见面时什么样，半年后什么样。
- **一定落回自己**：讲谁多厉害，最后都是"带她的过程中我学到了什么"。
- 不晒收入、不承诺"跟我干月入多少"。

### N. 节点圈
年终复盘、半年宣言、节日（母亲节写妈妈、情人节写爱自己）、里程碑（带瘦第 100 个人、早起第 365 天）。

### O. 生活留白圈
「陪孩子在小区玩。抬头看云，低头找蚂蚁。这会儿她又在研究路边的小石子。真好。」高强度分享之间，插一条毫无目的的生活画面。

### P. 负面逆转
「早上称重涨了两斤，有点烦 → 我能从里面学到什么？→ 原来是昨晚那顿 → 明天同一时间再称给你们看。」负面可以写，必须翻上来，用自嘲或新决定收。

### Q. 发圈打卡
「今天原创朋友圈 8 条。晚安@城市。」每晚最后一条公开自己的发圈数量，是自律证明，也给团队做示范。

## 六、高手的一天

| 时段 | 发什么 |
|---|---|
| 5:00-7:00 | 1-2 条一句话圈 / 早起打卡 |
| 7:00-9:00 | 减脂餐打卡；一条成长或金钱观点 |
| 9:00-12:00 | **高峰**：学员反馈 / 自己的打卡数据 / 读书笔记，3-5 条 |
| 12:00-15:00 | 午餐、生活小事、答疑、一句话圈 |
| 15:00-19:00 | 晒单 / 教练故事 / 家人故事 |
| 19:00-22:00 | 营养科普、长故事 |
| 22:00-23:00 | 当天最走心的长文、复盘、"晚安@城市" |

## 七、把写法用到自己身上

素材一律来自发圈人自己：读 `个人档案`（见 SKILL.md）里的身份、家人称呼、经历和口头禅，加上她这次发来的素材。**档案和素材里没有的事，不编；缺的数字和细节用【】留空让她填。**

| 写法里的 | 换成发圈人自己的 |
|---|---|
| 早起 / 打卡 | 早起第 N 天、减脂餐打卡、运动第 N 天 |
| 家人故事 | 档案里的老公、孩子、父母、婆家的称呼和真实故事 |
| 撕裂自己 | 档案里她愿意公开的过去（胖、穷、低谷） |
| 学员反馈 | 她自己学员的数据和原话 |
| 产品 | 团队在卖的营 / 方案 / 产品（见 `产品与合规.md`） |
| 招商 | 招减脂教练 |

## 八、不要学的

- **效果承诺**："不瘦包退""排出宿便""吃了就能瘦""一天瘦两斤""治失眠/治便秘"。团队是营养专业背景，只写真实过程和顾客原话。
- **贬低别人**："穷都是活该""胖是因为懒"。可以谈金钱观、谈自律，不踩人。
- **劝人借钱投入**："刷信用卡也要报名""越没钱越要投资自己"。
- **天天晒流水**：截图可以有，比例要低；信任主要来自专业和学员结果。
- **语录转发太多**：别人的话发多了，自己的故事就少了。每天至少一条自己的故事。
