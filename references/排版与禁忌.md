# 排版与禁忌

## 排版（文案 = 内容 + 排版，排版占一半）
朋友圈一行约 18 个字。
- **短文案**：1–3 行，一口气说完。
- **长文案**：首段 ≤ 3 行（最多 4 行）；中间每段 3–4 行（50–70 字），最多 5 行；故事最多 3 段；结尾一段，≤ 4 行。
- 段与段之间空一行。
- 标点打全，注意细节。表情最多 1 个，能不用就不用。
- 长文案超过约 6 行会被折叠成「全文」，所以**前 3 行必须让人想点开**。

## 语气
- 说人话，像坐对面唠嗑。不追求华丽，追求真实和感染力。
- 故事里不夹道理，道理留到结尾说一次。
- 有能量、有信心。允许狼狈，不允许丧到底。
- 不教育客户，不贬低别人的减肥方法让人觉得自己傻。

## 禁忌
1. 纯负能量（"今天好丧""完了完了"）。负面开头必须逆转。
2. 鸡汤摘抄不加自己的故事。
3. 读书笔记里打广告。
4. 天天只发产品，不发自己。
5. 只有"我"，没有他人。
6. 只讲一个面（只讲职场或只讲减肥），不全方位。
7. 文案里出现医疗承诺（"治好""根治""保证瘦 X 斤"）——用真实结果和过程代替承诺。

## AI 味自查（写完必过）
- 「不是 X，是 Y」全文最多 1 次。
- 并列段落不能用同一种收尾句式。
- 少用"其实""真的""说实话"堆砌；少用排比三连。
- 不要每段都以金句收尾；金句只在结尾出现一次。
- 有具体的人名称呼（老公、孩子的小名、学员姐妹）、具体数字（斤数、天数、时间）、具体画面（厨房、秤、体检单）。
- 句子长短混搭，允许口语化的短句独占一行。

再逐句看一遍，下面这些是机器写东西最常见的样子，碰到就改：

| 痕迹 | 长什么样 | 怎么改 |
|---|---|---|
| 太光滑 | 情绪一路顺着走：难过→领悟→温暖，没有一处卡住 | 留一处她自己也没想通、还在别扭的地方，别修圆 |
| 没有犹豫 | 每句都很笃定 | 加一句真实的不确定：「我也不知道这样对不对」 |
| 假细节 | 「那一刻我愣了 3 秒」「心跳漏了一拍」 | 换成她嘴上会说的：「我当时就懵了」 |
| 脆弱当工具 | 讲伤口只为了引出产品或道理 | 伤口写完可以不接道理；或留一个和论点无关、但她记得很清楚的细节 |
| 编出来的故事 | 「有个学员跟我说……」但没有称呼、没有出过岔子 | 用真实的称呼和一个意外细节；想不起来就换她自己的事 |
| 替读者说蠢话 | 「你可能觉得减肥就是少吃」然后纠正 | 只写真被人问过的话，原话照抄 |
| 拔高 | 一件小事最后升到「人生的本质是……」 | 删掉最后那句大道理，看看是不是已经结束了 |
| 连接词 | 「然而」「事实上」「值得注意的是」「作为一名教练」 | 删掉，换成嘴上说的「可是」「后来」「结果」 |
| 结尾祝福 | 「愿每个姐妹都能遇见更好的自己」「你值得」 | 删掉最后一段再读，多数时候已经结束了 |
| 开头卖焦虑 | 「你是不是也……？」「90% 的人都不知道」接一个承诺 | 从她真正想说的那件事开始 |
| 同义词轮换 | 同一段里「减肥」「瘦身」「减脂」「掉秤」换着说 | 她平时说哪个就一直用哪个 |
