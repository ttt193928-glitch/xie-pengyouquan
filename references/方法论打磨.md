# 方法论：选题、挖故事、打磨

这里只收**能用在朋友圈上的写作方法**，按朋友圈的长度改过。分两段用：
- **写之前**（第一、二部分）：今天写什么；怎么把一件事挖成一个故事。全方位分享、家人、撕裂自己这类长故事，**必须先过第二部分**。
- **写完以后**（第三到八部分）：第一句、结构、故事、金句、结尾，逐项打磨。

---

## 一、选题：今天写什么

### 1. 先找"自我表达"和"读者想看"的交集
只写自己想写的，是自嗨；只写读者想看的，写着别扭。每条圈先问一句：**这件事，我的读者（想瘦、想变好的女人）会不会在里面看到自己？**

### 2. 爆款十元素：一件小事 + 1-2 个元素，就有人看
- **三种感情**：亲情、爱情、友情
- **五种情绪**：暖心、愧疚、怀旧、孤独、愤怒（愤怒慎用）
- **两个标签**：群体（宝妈、四十岁、上班族、产后）、地域（小城、出租屋、老家）

例：「今天给孩子做早饭」是流水账；加上**愧疚**（以前总让他吃面包）+ **宝妈群体**，就是一条圈。

### 3. 三种出新角度的办法
- **换角色**：同一件事，换一个人的视角写。学员瘦了，别人都写学员，你写她老公的一句话、她女儿的反应。
- **硬组合**：把两个不相干甚至相反的东西放一起。「过年那天，我在健身房」「情人节，我教一个离婚的姐姐做减脂餐」。
- **小见大**：大主题不要大着写，找一个小物件、小场景。写"这些年的改变"，就写衣柜里那条从 XL 换到 M 的牛仔裤。

### 4. 热点怎么蹭
- 大家都在聊的剧、新闻、节日、天气，改一句话、找一个争议点，接到自己的事上。
- 评论区、学员的提问、群里的聊天，都是现成的选题：**爆款旁边一定有爆款**。

### 5. 不知道写什么时，从这些提示里挑一个（挑一个，写一个具体的时刻）
- **第一次**：第一次上秤看到那个数字；第一次收学员的钱；第一次穿上小一码的衣服；第一次跟家人说"我想做这件事"。
- **转折点**：哪一天、哪一句话让你决定改变？
- **抉择**：一个说"好"或说"不"的时刻；一个你没有做、后来后悔的决定。
- **失而复得**：丢了又找回来的东西、关系、身材、自信。
- **被逮个正着**：偷吃被孩子看见；说了大话被打脸。
- **出丑和失败**：最尴尬、最想删掉的一次。
- **物件**：一张老照片、一件旧衣服、一个用了很多年的碗，它背后的事。
- **别人的一句话**：一句一直记到今天的话（好的坏的都行）。
- **打破习惯的那一天**：今天和平常哪里不一样？不一样的那一刻，往往就是故事的开头。

## 二、挖故事：把一件事挖成一个故事

### 1. 故事和流水账的区别：有没有"变化"
发生了一件事，不叫故事。**故事 = 开头的我 → 经历了这件事 → 结尾的我不一样了。**
写之前先回答：这件事之前，我是什么样？之后，我哪里变了？（变得更懂、更狠、更软、更勇敢、和某个人的关系变了……）答不上来，就还没挖到。

### 2. 先用一句话说清这个故事
写之前，用一句话概括：「这是一个关于______的故事。」
同一件事可以挖成好几个故事（例：跑完马拉松，可以是"关于坚持"，也可以是"关于老公第一次来终点等我"），**一句话定了，细节才知道留哪些、删哪些**。这句话不用写进正文。

### 3. 找"利害"：你当时想要什么、怕失去什么
没有利害，读者就不关心。写清楚：当时**我最想要的是什么？什么在挡着我？如果失败了，我会失去什么？**
例：丢了行李不算故事；行李里有唯一一张外婆的照片，读者立刻揪心。
要把"利害"提前埋好：先交代那张照片有多重要，后面丢的时候读者才会跟着急。

### 4. 找"抉择"：故事的核心是你怎么选的
发生了什么没那么重要，**读者真正想知道的是：你决定怎么办。** 吃还是不吃、说还是不说、走还是留。没有行动也是一种选择（当时没开口，后来后悔）。

### 5. 去挖最不想讲的那件事
- 人都想讲光彩的事，但"我多厉害"的故事读者会烦。**成就只能当背景，故事要讲你怎么跌跌撞撞走过来的。**
- 想起来就尴尬、就不想讲的那件事，往往正是最好的故事。
- **示弱就是力量**：你承认自己搞砸过，读者才会靠近你、信任你。
- 但苦难本身不是故事：只有"发生了一件坏事"、只有抱怨，读者不是你的心理医生。苦难要写到你从里面走出来、学到了什么。

### 6. 只写自己亲历的
写别人的事，要写这件事**对你的影响**。家人、学员的故事，主角还是"我看到了什么、我变了什么"。

### 7. 不要拿别人当道具
不写"她那么胖还……让我觉得自己幸运"这种拿别人做反衬的故事。不在故事里翻旧账、说前任/婆婆/同事的坏话——读者会本能地去保护不在场的人。

## 三、第一句：朋友圈的第一句就是标题

### 1. 三个误区
- **太长**：第一句超过两行，折叠后读者看不全。
- **信息太多**：一句话里塞两个爆点，等于没有爆点。聚焦一个。
- **把第一句当总结**：第一句不是概括全文，**只有一个目的：让人点开"全文"**。

### 2. 两步写第一句
**先找"敏感词"，再套句式。**
敏感词就是读者一看就想点的词：减肥、体重、饿、胖、老公、婆婆、孩子、离婚、产后、四十岁、钱、熬夜……（每个人的读者不一样，记下自己哪些圈互动最多，里面的词就是你的敏感词）

### 3. 九种句式

| 句式 | 示范 | 要点 |
|---|---|---|
| 数字法 | 「21 天，腰围少了 6 厘米？」「90% 的妈妈都这样饿过自己」 | 数字要具体或够大 |
| 对比法 | 「别人在国外买大牌，她在菜市场把自己吃瘦了」「谁不是一边想瘦，一边想吃」 | 反差越大越好；"一边…一边…" |
| 热词法 | 「看完《XX》，我哭着吃完了一盒沙拉」 | 热词要真的热 |
| 疑问法 | 「为什么越节食越胖？」「不吃晚饭真的能瘦吗？」 | **核心是反常识**，问一个和常识相反的问题 |
| 对话法 | 「"你都多大了还减肥？""就是因为多大了才要减。"」 | 前半句是生活里常听到的话，后半句有力还击 |
| 好奇法 | 「这 3 句话，胖过的人都听过」 | 话说一半，最好配数字 |
| 俗语法 | 「人生没有白走的路，也没有白吃的宵夜」 | 改编大家熟悉的话，押韵更好 |
| 台词法 | 改编一句大家熟悉的歌词、台词 | 轻松圈用 |
| 故事感 | 「她进营第三天，哭着给我打了个电话」 | **最好的第一句，一眼就有故事感** |

### 4. 第一句不要和产品连在一起
第一句就出现产品名，读者一眼看出是广告，直接划走。产品放在后面。

### 5. 自测
- **想 3-5 个第一句**，挑一个。
- 只看第一句，**你自己想不想点开？** 不想，就重写。
- **跟读者有没有关系？** 是她关心的、她想知道的吗？

## 四、开头的其他写法（第一句之后的前三行）

| 开头 | 朋友圈里的样子 | 检查点 |
|---|---|---|
| 问句式 | 「晚上饿到睡不着，是你意志力差吗？」 | 有悬念、有共鸣、能接上下一句 |
| 对话式 | 「"你这么吃，能瘦才怪。"我老公昨晚说的。」 | 选全篇最有爆点的那句对白提到最前，要短 |
| 互动式（你） | 「你是不是也一到晚上十点就想翻冰箱？」 | 用"你"把读者拉进熟悉的场景 |
| 自我表达式（我） | 「我前 30 年最大的本事，是减肥失败。」 | 要么自黑自嘲，要么做的事很特别 |
| 悬念式 | 先写最关键的那一刻，停住，再倒回去讲 | 倒回去的部分要短，很快回到那一刻 |
| 学员投稿式 | 「昨晚一个学员发来一大段话……」 | 借别人的口引出观点，最适合我们 |

**开头的禁忌**：不要用"今天想跟大家分享一件事""事情是这样的"这种热身句；不要先剧透"接下来发生了最不可思议的事"——直接让它发生。

## 五、结构（长文案用，短圈跳过）
- **观点 + N 个事例**：一个观点，两三个具体的人/事印证，最后回到读者。
- **大观点 + N 个反常识小观点**：适合干货圈，每个小观点配一个小例子，结尾补一句辩证的话缓冲。
- **观点 + N 个角度**：同一件事从吃、睡、家人、钱几个场景写。
- **一个人的 N 个片段**：写学员/家人，挑几段经历串起来，最后才亮观点。
- **故事三要素交替**：**场景**（放慢，写细节）→ **概述**（一句话带过时间："三周后""那一年"）→ **反思**（我当时怎么想、后来明白了什么）。全是场景太长，全是反思太虚，要交替。

## 六、故事（骨架 + 血肉 + 引爆）

### 1. 4 步搭骨架
一句话（开始→结果）→ 定冲突（出了意外）→ 给理由（为什么）→ 组合。没有冲突的故事就是流水账，先找冲突。

### 2. 3 步补血肉
交代背景（谁、什么关系、当时处在人生什么阶段）→ 补一个关键信息（为后面埋伏笔）→ 设计一个情绪爆点（一句原话、一个画面）。

### 3. 场景：像拍电影一样写
- 问自己：**如果这是电影，哪个镜头最让人移不开眼？** 那就是你要放慢写的场景。
- 一个故事通常只有**一个最重要的场景**（高潮），把力气花在那里。其他的用一句话带过。
- 写场景时站在**当时的自己**里：当时不知道结局，就别提前说"后来我才知道"。

### 4. 细节：让画面从黑白变彩色
- 不写"我很焦虑"，写"灯开了又关，关了又开"。情绪全部换成动作、物件、声音、气味、一句原话。
- 写人不贴标签（"我婆婆很节省"），写一个细节（"她把用过的保鲜袋洗干净晾在阳台上"）。
- **埋一个宝**：开头随手提一个小物件（一张照片、一个饭盒），中间放下不管，结尾再拿出来，读者会被击中。
- **细节过多的坑**：日期太多、人名太多、和主线无关的细节、血淋淋的细节、自相矛盾的细节，都删掉。"我不太记得了"这种话也别写。
- 只写自己知道的：不写"她肯定觉得我很傻"，写"她看了我一眼，我马上担心她觉得我很傻"。

### 5. 打乱顺序
- **悬念开头**：先写最关键的那一刻，停住，倒回去讲来龙去脉，最后回到那一刻。
- **中间插叙**：讲到紧张处，插一小段过去，再回来。插叙要短。
- **首尾呼应**：结尾回到开头那个场景，同一个画面，意思已经变了。

### 6. 幽默
- 幽默来自真实的细节和自己的反应，不是硬加段子。
- 紧张、难过的段落之后，一个真实的好笑细节能让读者喘口气。
- 用笑话躲开真正的情绪，读者会觉得你在推开他们。

真实感来自细节：时间、地点、人物当下的心理和小动作。细节到位，读者就信。

## 七、金句（全篇只留一句，放在高潮或结尾）
| 模板 | 套路 | 减脂场景例子 |
|---|---|---|
| 1221 式 | 两个词前后换位置，意思反转 | 「你以为是你管着嘴，其实是嘴一直在替你扛情绪。」 |
| 1213 式 | 同一个词，前后搭不同的词形成反差/递进 | 「别人减肥是为了好看，我减肥是为了好好活。」 |
| 否定法 | 先说常识，再推翻 | 「我以为胖是一顿一顿吃出来的，后来发现，是一天一天熬出来的。」 |
| 具象法 | 抽象情绪换成一个具体东西 | 「自律就是早上那颗没剥壳也要带上的鸡蛋。」 |
| 扩字法 | 在常见句子上加两三个字，意思变深 | 「我以为她们怕的是胖，其实她们怕的是被别人看见胖。」 |
| 搜词法 | 抓核心字，找同字词组合 | 「瘦」→ 消瘦/清瘦/瘦身……挑两个组成对照 |
| 拆字法 | 把字拆开赋予意义 | 慎用，容易牵强 |

金句必须先有观点，套模板只是把观点压缩成一句话。没观点硬套就删掉。

---

## 八、结尾（离点赞和评论最近的地方）
- **峰终定律**：读者只记住最高潮和最后一句，结尾要么有情绪，要么有行动。
- 好的结尾要让读者看到**"变化"**：开头的我和结尾的我不一样了。最后一句和第一句一样重要。
- 朋友圈常用：
  - 关联读者：「你是不是也……」，把事落到读者身上。
  - 一句金句收：从第七部分挑一个。
  - 行动/约定：「明早同一时间，我再上秤给你们看。」
  - 首尾呼应：回到开头那个场景或物件。
  - 戛然而止：故事讲完就停。
- 不写"所以这个故事告诉我们……"；不用排比式结尾（AI 味重）；名人名言收尾一个月最多一两次。

## 九、最后过一遍
- 变化：开头的我和结尾的我，哪里不一样了？
- 利害：读者知道我当时在乎什么、怕失去什么吗？
- 情绪：读完有没有一个让人"心里一动"的点？传播的本质是情绪。
- 画面：每段至少有一个读者能"看见"的东西。
- 第一句：只看第一句，你自己想不想点开？
- 断句：大声读一遍，卡壳的地方断开或删掉。
