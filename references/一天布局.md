# 一天的朋友圈布局

综合两份依据：
- 方法：三驾马车（早起 / 读书笔记 / 每日复盘）+ 每天一条长文案 + 五大板块。
- 高手节奏：日均 6-10 条，8-10 点最高峰，21-23 点发当天最走心的长文（详见 `写法拆解.md` 第六节）。

## 底线规则
- **每天至少 1 条长文案**（全方位分享，讲自己的故事）。可以一天不发广告，不能一天没有故事。
- **三驾马车每天都有**，用连续编号（第 N 天），数字本身就是证据。
- 广告类（广告圈 + 晒单 + 招商）**不超过当天总数的 1/3**，并且分散在不同时段，不连着发。
- 发圈数量建议：起步期 6-8 条，冲刺期（开营、招教练前）10 条以上。

## 标准日（8 条版）

| 时间 | 板块 | 写什么 | 配图 |
|---|---|---|---|
| 06:00-07:00 | 价值·早起 | `早起第N天` + 一个当下的小画面 + 今天最想做成的一件事 | 窗外/早餐/镜子自拍 |
| 07:30-08:30 | 价值·专业 or 一句话 | 一个减脂误区纠正（"多吃水果不吃肉能瘦？"）或一句观点金句 | 食物图/无图 |
| 09:00-10:30 | 广告·学员反馈 | `X天瘦X斤？` + 这个人是谁 + 过程细节 + 结果 | 对比图/体重截图/聊天截图 |
| 12:00-13:30 | 日常分享 | 午饭、减脂餐、和谁吃饭、一件小事；可顺带好物 | 实拍 |
| 15:00-17:00 | 晒单 / 招商（二选一） | 收学员的故事，或带出来的教练的变化 | 截图（遮挡隐私） |
| 18:00-19:30 | 日常分享·家庭 | 接孩子、做饭、老公一句话，短 | 生活照 |
| 21:00-22:30 | **全方位分享·长文案** | 当天最走心的一条：家人、过往、野心、金钱观、我和他人的关系 | 合影/老照片/单人照 |
| 22:30-23:30 | 价值·复盘 | `复盘第N天`：一个反思 + 今天做了什么 + 明天安排 | 手写复盘/无图 |

## 特殊日调整
- **开营前 3 天**：加 1-2 条广告圈（往期学员故事 + 营期安排 + 剩余名额），长文案照常。
- **开营当天**：早上发"今天开营"，白天晒群里的第一批反馈，晚上长文写"为什么要做这个营"。
- **招教练期**：每天 1 条招商圈，写一个教练的具体变化，最后落回"我在带她的过程中自己学到了什么"。
- **低落/出事的日子**：照发三驾马车；长文案可以写这件事，但要写到"我从里面学到了什么"。

## 输出格式（流程 B）

```
【今日主线】（例：开营前第2天 / 普通日 / 招教练周）

06:30 ｜ 价值·早起 ｜ 早起第128天：……（一句话写法提示） ｜ 配图：……
09:30 ｜ 广告·学员反馈 ｜ ……
……
21:30 ｜ 全方位分享 ｜ ……（直接写出全文）
```

用户给了今天的素材时，把素材放到最合适的时段，并把**晚上的长文案直接写出全文**，其余条目给一句写法提示即可；用户要求时再逐条展开。
