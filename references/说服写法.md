# 说服写法

有一类圈，任务不是让人心疼你，而是**让人认同一个道理**：观点圈、认知圈、价值输出、"我发现一类学员……"。
这类圈写不好，通常是三个毛病：只有态度没有理由；拿自己的伤口去软化，读者注意力跑到你身上；故事讲完就走，没讲清它说明了什么。

---

## 一、先把核心判断问到底

动笔前，把她的感受翻成一句**能拿来检验**的判断。只说"是什么"不够，还要说出"规矩是什么"和"凭什么"。

| 只到一半 | 问到底 |
|---|---|
| 减肥要做个不破场的人 | 减肥是一个场合，这个场合的规矩是**客观**：身体只认吃进去多少、用掉多少，不认你爱不爱吃 |
| 减肥要坚持 | 体重是滞后的，今天吃的要过几天才上秤，所以看一天的数字没有意义 |
| 别跟别人比 | 每个人起点的代谢、肌肉、作息不一样，同一份餐单在两个人身上就是两件事 |

- 她已经说清了观点，就沿着她的话往下问到底，不另起炉灶。
- 她只给了一个感受、观点还模糊，**先给 2-3 个核心判断**（每个一句话），让她挑一个再写。

核心判断里要有一个**主题词**（如"客观""滞后""起点"）。后面每一层都围着它转，结尾落回它。

---

## 二、论证链（按顺序）

1. **一个人人都认的场景**：她今天亲眼看到的事，或者生活里谁都见过的事。先让读者点头，不设防。场景本身最好就带着那条规矩（"发令枪一响，你还蹲着玩沙子，名次不会等你"）。
2. **一个故事**：结构和观点一样的故事、寓言、典故、别人的经历。讲法见第三节。
3. **把主题词说成大白话**：「什么叫客观？就是你看、我看、谁看都一样的东西：秤上的数字，腰围的尺子。」再说它的反面。两边一摆，读者自己看出站在哪边。
4. **读者自己最常说的那句话**："这个我不爱吃""我已经吃得很少了"。原话放出来，后面**不接质问**，接一个照镜子：「在她心里，句句有理。就跟那个新娘子一样。」
5. **一个理由或证据**：一句原理、一个研究发现、一个人人可验证的事实（"秤不动，就是你吃的没有你以为的那么少"）。只放一两个，放多了像上课。
6. **一个能做到的台阶**：说完重话马上给出路，而且是做得到的期限或动作（"最难的就是头一个礼拜，头过了，身子就过了"）。
7. **结尾首尾呼应，落回主题词**：回到开头的场景，用一个画面收（"孩子有老师喊，大人没人喊了，秤每天早上都在喊"），不另起一句大道理。

不是每条都要七层齐全。短一点的观点圈，可以只用 1、3/4、6、7。

---

## 三、故事怎么讲透

故事是说服圈里最有力的一块，也是最容易讲废的一块。

**找故事**：故事和观点要**结构一样**，题材不用一样。先用一句话说出观点的结构，再去找：
- "话没错，错在身份和时机不对" → 新娘子刚进门就指挥婆家
- "嫌麻烦的步骤，恰恰是最省事的" → 磨刀不误砍柴工
- "一点一点的小事累积成大事" → 千里之堤，溃于蚁穴

去哪找：观点库里能讲成故事的条目；大家都知道的成语、寓言、典故（揠苗助长、磨刀不误砍柴工、千里之堤溃于蚁穴……按通行讲法写，拿不准的细节标出来让她核对）；她或学员的真实经历。**不编人物和经历。**
跨题材的故事说服力最强：读者在别的事上先认了理，再回到减肥就没法不认。同样是减肥的真实案例，放进第二节的「一个理由」那一层更合适。

**讲故事**：
1. 用大白话讲，保留有画面的细节（马、灶火、石臼），三五行讲完。
2. **讲完追问一句**，让读者自己答：「你看，她哪句话说错了？一句都没错。」
3. **点明错在哪**：「可她才刚进门，这些话，还轮不到她说。」
4. **接回主题**：「她错就错在，没看清自己在什么场合。」再用一句把读者扣进来：「就跟那个新娘子一样。」

**不要**：故事讲完直接跳到下一段；一条圈塞两个以上故事；故事细节张冠李戴、凭记忆乱编。

---

## 四、软的部分放在哪

说服圈也要软，但软在**出路**上，不软在发圈人的伤口上：
- 好：「好在，口味是养出来的。」「不爱吃可以跟我说，我帮你换。」
- 慎用：讲自己的伤心事来缓和语气。它会让读者心疼你，道理就没人记了。真想讲，留给单独一条撕裂自己的圈。

狠话最多一句，放在证据后面，像是证据推出来的，不像是你在骂人。

---

## 五、说服圈自查

- [ ] 核心判断有没有说到"规矩是什么、凭什么"？有没有一个主题词？
- [ ] 开头的场景，读者会不会先点头？
- [ ] 故事讲完有没有追问、点明、接回？
- [ ] 读者心里那句反驳，有没有正面回应？回应的是照镜子，不是质问？
- [ ] 有没有一个做得到的台阶？
- [ ] 结尾有没有落回开头和主题词？
- [ ] 删掉故事，道理还立得住吗？删掉道理，故事还有意义吗？（两样都要立得住）
