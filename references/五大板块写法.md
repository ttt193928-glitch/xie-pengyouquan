# 朋友圈五大板块写法

底层逻辑只有两条：**你是主角 + 提供价值**。最终目的是成交（零售顾客 / 减脂教练 / 弟子），手段是信任。
信任链：认识你 → 了解你 → 信任你 → 买单。朋友圈的任务是把人推过这条链，做到"透明人生意"：客户没见过你，却比你自己还了解你。

销售的终极秘诀是**传递信心和能量**。每条圈写完问一句：读完的人对我、对减肥这件事，信心是多了还是少了？

---

## 1. 全方位分享（最重要，每天至少 1 条长文案）

**全方位分享 = 日常分享 + 核心分享**

### 日常分享 = 家庭关系 + 兴趣爱好 + 好物推荐
- 家庭关系：老公、儿子、爸妈、弟弟、婆婆、奶奶、姑姑。像跟闺蜜说悄悄话。
- 兴趣爱好：看过的书、电影、剧，练臀、运动，中医。
- 好物推荐：口红、护肤、厨房小工具、某家店、某个酒店。人性懒，你推荐的好用，就会觉得你推荐的都靠谱。

### 核心分享 = 敢于撕裂自己 + 展示野心
- 撕裂自己：产后抑郁、饿瘦的代价、胖回来、和弟弟的矛盾、裸辞国企、不孕三年、小黑屋。常人不敢写的，写出来就是人格魅力。
- 展示野心：直说爱钱、想赚钱、想带出多少个教练、想让家人想买就买。线上低调就是怂。

### 系列：我和他人的关系（制胜板块，点赞最高）
我和老公 / 我和弟弟、娘家 / 我和婆婆 / 我和顾客学员 / 揭秘人情世故。
- 圈里天天"我我我"没有他人，说明心里没别人，没温度。
- 常用首句：「谢谢你，有你在真好。」配两人合影或单人照。

### 系列：我和金钱的关系
金钱观、消费观、给家人花钱、买了什么。金钱是世俗世界的核心，敢谈钱才有宣传点。

### 写法要点
- 像看连续剧：今天讲一段，明天接着讲，日积月累把一个立体的人讲完。
- 负面情绪必须做**剧情逆转**：可以从"今天本来很烦"开头，结尾一定翻上来。纯伤春悲秋不招财。
- 狼狈比优雅动人：一地鸡毛不怕，要写出"受挫但仍坚挺"的状态。

## 2. 价值输出

不是摘鸡汤（鸡汤 = 0 分），是借一句话讲出**自己的感悟和改变**。

### 三驾马车（每天固定，用连续数字制造震撼）
| 马车 | 价值类型 | 写法 |
|---|---|---|
| 早起打卡 | 情绪价值、自律 | `早起第 N 天` + 一句今天的状态/计划/一个小画面，短，有能量 |
| 读书笔记 | 思维价值 | 总-分-总：金句 → 我的故事 → 我的改变 |
| 每日复盘 | 时间管理 | `复盘第 N 天` + 今天做了什么（1.2.3.）+ 一点收获 + 明天计划 |

其他连续打卡同理：减脂餐 365 天、练臀第 N 天、学员反馈第 N 位。数字本身就吸引人。

### 读书笔记框架（一切文案的鼻祖）
1. **观点**：书中金句，1–2 行，短小精悍。
2. **故事**：围绕金句讲自己的经历，说人话，像坐对面唠嗑。用「记得……」「一个多月前……」「那天……」直接进故事，别一上来就"教导主任附体"讲道理。故事最多 3 段。
3. **结论**：我学到了什么、改变了什么，和开头呼应，一段收尾。

读书笔记**不打广告**，是一片净土，用来破冰、秀自己。

### 专业知识
慢慢积累。减脂原理、饮食搭配、平台期、体检指标、中医养生。用顾客案例带出来，比干讲好。

## 3. 广告圈（项目圈）

四类：**产品铺垫、产品打卡、硬广软广、晒对比图**。

### 零售（C 端）出单最有效的写法
描述**肥胖类型 → 瘦身过程 → 瘦身结果**，就能拿到精准咨询。
- 例：「大基数宝妈，产后 2 年 150 斤，腰腹型。第一周……第三周卡了平台……现在 128 斤，体检血脂正常了。」
- 配对比图/体重秤/聊天截图。
- 软广：从生活故事切入，最后落到"所以我这么带学员"。硬广：直接讲营的时间、名额、适合谁、怎么报。

---

## 4. 晒单圈

三类：晒收学员、晒团队出单、晒团队成员出单。体现**红红火火**，让人觉得别人都在买，我也要加速。

### 晒收学员 / 收减脂教练写法
**开头直接介绍客户 → 她为啥选我、选这个方案 → 升华**。核心是讲她的故事，不是只晒个转账截图。
自己没单就晒团队的，借力团队。

---

## 5. 招商圈（减脂教练、入室弟子）

五类：**学员圈、老师圈、同伴圈、品牌圈、团队圈**。课程、培训、群里对话、福利、老师牛，都算。

**核心写法：不管讲谁多牛，一定转回自己身上**——我的变化、我的故事、我在这里的成长。你本人的变化才是别人最想看的。

半遮半掩的截图（课程资料、群聊、收入）比全部晒出更勾人。

---

## 灵魂：人际关系 = 颜值 + 能力 + 情商
- 颜值：瘦、妆、穿搭、照片质感。人性肤浅，顺应它。
- 能力：文案、摄影、视频、专业。
- 情商 = 嘴甜 + 给钱 + 捧场，但有自己的框架，不见人就夸。
- 别人有礼，我们更有礼；别人高高在上，我们淡淡。不跪流量、不跪有钱人。
- 爱出爱返：没有人会拒绝真诚的爱。不教育客户，不说"你傻"。
