# 观点库索引

626 条大白话观点，按朋友圈的板块分类。写圈时先判断素材属于哪一类，打开对应文件挑 1-2 条。
一件事常常能跨类：比如"跑完马拉松"可以用「日常生活」的跑步观点，也可以用「我和自己」的坚持观点，或者「我和家人」的感谢观点。挑最能拉近信任的那一个。

每条的格式：
- **观点**（一句大白话）+ 展开
- **适合写**：什么素材用它
- **示范**：一句示范写法——只是示范，必须换成发圈人自己的经历，不能原样照抄

通用规则：观点只占一两句，主角永远是发圈的人；不写书名、作者、出处。
