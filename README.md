# 写朋友圈

减脂教练团队的朋友圈写作助手（AI 技能，支持 WorkBuddy 等能装技能的 AI 助手）。

把今天发生的事、学员的一句话、一张反馈截图发给它，它帮你：
- 判断今天该发哪类圈、几点发、配什么图
- 想好第一句，把一件小事挖成一个故事
- 写出一条可以直接复制的朋友圈，用的是你自己的说话方式
- 守住产品宣传的合规红线
- 不知道发什么时，给你选题；也能排一整天的朋友圈

---

## 安装（只需要一次）

前提：电脑上已经装好 WorkBuddy（或其他支持技能的 AI 助手）。不需要 GitHub 账号。

打开终端，复制粘贴这一行，回车：

```bash
git clone https://github.com/ttt193928-glitch/xie-pengyouquan.git ~/.workbuddy/skills/写朋友圈
```

装好后重新打开 WorkBuddy，输入 `/写朋友圈`，或者直接说「帮我写条朋友圈」。

> 用的是其他 AI 助手：把命令最后的路径换成那个助手的技能文件夹就行（例如 `~/.agents/skills/写朋友圈`）。

## 第一次用

它会先问你几组问题（怎么称呼你、家里有谁、你自己的减肥经历、口头禅、主推什么），用来建你的个人档案。不想答的可以跳过。
档案只存在你自己电脑上（`~/写朋友圈/我的档案.md`），不会上传。

## 本机扩展（可选）

如果 `~/写朋友圈/` 下有一个 `本机扩展.md`，技能每次写圈都会读它，并照里面写的额外步骤做，比如多查一份你自己的素材。
这个文件只在你自己电脑上，别人看不到，也不会随更新覆盖。只放你自己写的内容，别人发来的扩展文件先打开看清楚再放进去：里面写什么，技能就会照着做。
不需要的话不用建，没有这个文件技能照常工作。

## 更新

技能有更新时，在终端运行：

```bash
git -C ~/.workbuddy/skills/写朋友圈 pull
```

## 怎么用效果最好

- **素材越具体越好**：截图、原话、时间、数字、当时手里拿着什么。
- **它不会替你编经历**。缺的地方会用【】标出来，你自己填。
- 写出来不满意，直接说「再来一版」「换个角度」「太长了」。
- 涉及产品的圈，功效只能用顾客原话，发之前记得把截图里的头像、昵称打码。
